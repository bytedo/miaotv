# 跳过片头片尾

在播放页打开“跳过设置”，可以按时间跳过片头、片尾，也可以在片尾直接播放下一集。这里使用手动设置的时间范围，不会分析视频画面来识别片头。

## 设置时间

1. 播放视频后打开“跳过设置”。
2. 填写片头起止时间和片尾时间；也可以播放到对应位置，点击“标记”填入当前时间。
3. 选择“自动跳过”和“自动下一集”。
4. 点击“保存智能配置”。

时间支持秒数和“分:秒”，例如 `90`、`1:30` 和 `1:30.5`。

| 片尾模式 | 填写示例 | 含义                           |
| -------- | -------- | ------------------------------ |
| 剩余时间 | `2:00`   | 视频还剩 2 分钟时进入片尾范围  |
| 绝对时间 | `20:00`  | 播放到第 20 分钟时进入片尾范围 |

同一部剧各集时长不同时，剩余时间通常更方便。片尾还有彩蛋或预告时，先关掉自动跳过，确认时间后再启用。

“高级设置：添加单个片段”可以用秒数保存额外片段，已保存片段可单独删除。从 0 秒开始的片头使用上面的批量设置。批量保存会用面板里的片头、片尾替换当前片段列表；关闭面板不会保存改动。

## 默认行为

还没有保存配置时，面板预填片头 `0:00–1:30`、片尾剩余 `2:00`，播放器会据此生成临时跳过范围。自动跳过和自动下一集读取当前浏览器的偏好，初始值均为开启。

这些时间不一定适合当前视频。默认规则还会根据视频时长限制触发范围：少于 5 分钟的视频不会使用默认的 90 秒片头范围，默认片尾也不会从视频前 60% 开始。

删除全部片段后，会重新使用临时规则。要停止自动跳过，应关闭相应开关；已有片段还需保存修改后的配置。

## 播放时会发生什么

- 开启自动跳过：进入片段后立即跳过，普通片段跳到结束位置之后。
- 片尾同时开启自动下一集：进入片尾范围后立即请求下一集。
- 关闭自动跳过：显示手动跳过按钮，按钮会在一段时间后隐藏。
- 手动点击片尾跳过：有下一集回调时会请求下一集。

当前实现没有“5 秒后自动播放下一集”的倒计时。需要保留片尾内容时，提前关闭自动跳过或调整时间。

## 复用预设

“跳过预设组”可以把常用的片头结束时间和片尾剩余时间存起来：

1. 填好时间，输入预设名称并创建。
2. 在另一部影片中选择预设，点击“套用到当前”。
3. 检查时间后，点击“保存智能配置”。

预设最多保存 20 条，保存在当前浏览器。可以导出为 JSON，也可以导入后选择合并或覆盖。预设不包含完整的多片段列表，绝对时间模式的片尾不会作为剩余时间保存。

## 配置存在哪里

存储方式由站点的 `NEXT_PUBLIC_STORAGE_TYPE` 决定。

| 数据                     | 本地存储模式                      | 数据库存储模式                         |
| ------------------------ | --------------------------------- | -------------------------------------- |
| 影片跳过配置             | 当前浏览器，按 `source + id` 保存 | 登录账号的服务端数据，可在设备之间读取 |
| 自动跳过、自动下一集偏好 | 当前浏览器                        | 当前浏览器                             |
| 跳过预设组               | 当前浏览器，可导出                | 当前浏览器，可导出                     |

同一个 `source + id` 下的各集共用时间设置。数据库模式还会优先用豆瓣 ID，或“标题 + 年份”生成影片标识，让不同视频源复用配置；缺少这些信息时仍按来源和 ID 保存。换源后若剪辑长度不同，需要重新检查时间。

清除浏览器数据会移除本地配置、偏好和预设。服务端数据的保留取决于账号和数据库备份，不应把它当作永久保存。

## 排查

设置面板打不开时，先等影片和视频源加载完成。跳过时间不准确时，确认总时长已经取得、片尾模式正确，再用“标记”重新填写。

改动后没有生效，先确认点击了保存，并检查当前片段的自动跳过选项。同一集已经处理过的片段可能不会再次触发，重新进入该集后再验证。
