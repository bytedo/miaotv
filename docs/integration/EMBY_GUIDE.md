# Emby 影库

MiaoTV 可以连接已有的 Emby 服务器，浏览媒体库、搜索电影和剧集，再进入播放页观看。服务器地址、账号和媒体内容需要自行准备。

## 启用条件

站点配置中的 `SiteConfig.EnableEmby` 必须为布尔值 `true`。这个功能默认关闭，字符串 `"true"` 不会启用它；关闭时导航和相关 API 都不可用。目前没有独立的后台开关，站长使用服务端存储时可按 [Emby 和 WebSR 开关](../deployment/CONFIGURATION.md#emby-和-websr-开关)一节操作。

个人源需要登录并使用数据库存储。站点采用 `localstorage` 模式时，服务端不会保存个人 Emby 源，只使用站点级配置。

## 添加个人源

在用户设置中找到“Emby私人影库”，点击“添加 Emby 源”：

| 字段       | 填写方式                                          |
| ---------- | ------------------------------------------------- |
| 标识符     | 简短且不重复的 key，例如 `home`；创建后不可修改   |
| 名称       | 列表中显示的名称                                  |
| 服务器地址 | 带协议的完整地址，例如 `https://emby.example.com` |
| 认证方式   | 选择密钥认证或账号认证                            |
| 启用此源   | 选中后才会出现在影库中                            |

密钥认证需要 API Key，用户 ID 可选。未填写用户 ID 时，客户端会尝试取得 Emby 用户列表中的第一个用户；需要指定媒体权限时应填写对应 ID，或直接使用该用户的账号认证。

账号认证需要用户名。只有 Emby 账号本身没有密码时，密码才可以留空。填写完成后测试连接并保存。

## 公共源与私网服务器

管理员可在后台“Emby 影库”添加站点级源，并打开“设为公共源”。启用的公共源会出现在普通用户的影库中；未公开的管理员源只对有管理权限的账号可用。

个人源和公共源使用相同标识符时，个人源优先。给它们使用不同的 key，更容易分清实际连接的是哪一台服务器。

普通用户保存一个私网地址，不会自动获得服务端的私网访问许可。私网 origin 必须匹配管理员配置中启用且公开的 Emby 源，协议、主机和端口都要一致；管理员可以明确配置或测试自己的来源。回环、链路本地、云元数据等地址仍会被拒绝，详见[代理与来源授权](../advanced/PROXY_CONFIG.md)。

## 播放选项

先用默认选项测试，再根据服务器要求调整：

| 选项               | 实际行为                                                                    |
| ------------------ | --------------------------------------------------------------------------- |
| 移除 /emby 前缀    | 默认会补齐 `/emby` 路径；开启后移除该前缀，适用于使用根路径的服务           |
| 拼接 MediaSourceId | 在直接流地址中加入 PlaybackInfo 返回的媒体源 ID                             |
| 转码 mp4           | 当前实现请求 `master.m3u8`，指定 AAC 音频；名称沿用旧界面，实际播放使用 HLS |
| 视频播放代理       | 浏览器从本站读取播放流，再由本站请求 Emby，会消耗本站带宽                   |

启用转码后，实际能否播放取决于 Emby 的转码能力、账号权限、服务器负载和视频编码。它不是所有 MKV 或音频格式问题的通用修复。

公共源列表接口不返回密钥，但直连播放、海报和字幕 URL 可能带有 Emby 访问凭据。视频播放代理也不等于代理所有图片和字幕。不要把完整播放链接或未脱敏的网络日志公开分享。

## 浏览与搜索

打开 `/emby` 后，在页面上方选择来源和媒体库。列表支持名称、添加时间、上映时间排序，以及升序、降序切换。输入搜索词后可以在当前选定库内搜索；点击卡片进入播放页。

“刷新”会重新请求浏览器端的 Emby 查询。服务端仍可能使用缓存：名称升序的列表和搜索索引缓存为 6 小时，媒体库视图为 24 小时；重启服务会清空这些内存缓存。因此页面刷新不一定立即反映服务器上刚添加的内容。

列表还支持[虚拟滚动](../features/VIRTUAL_SCROLL_GUIDE.md)，可从筛选区域关闭，用于比较布局问题。

## 排查

### 看不到入口

确认 `EnableEmby` 已启用并刷新页面，再检查账号下是否有启用的个人源或公共源。只填写地址但没有启用来源，不会显示媒体内容。

### 连接测试失败

在运行 MiaoTV 的服务器上确认 Emby 地址可达，而不只是确认自己电脑能打开。检查协议、端口、`/emby` 路径、API Key 或账号。私网请求被拒绝时，按来源授权规则检查配置，不要通过关闭网络检查解决。

### 有列表但播放失败

先在 Emby 自己的网页端播放同一媒体，确认文件和权限正常。再区分是格式、音轨、网络还是浏览器跨域错误：音频不兼容可尝试转码选项，跨域限制可尝试视频播放代理；启用代理后还需确认 MiaoTV 服务器能读取播放流。

### 剧集或媒体没有更新

确认 Emby 完成了扫描，检查所选媒体库，再刷新列表。如果服务端缓存尚未过期，联系管理员检查缓存状态。

## 接口与实现

这些接口需要站点开启 Emby，并验证当前登录账号：

| 接口                                    | 用途                                    |
| --------------------------------------- | --------------------------------------- |
| `GET /api/emby/sources`                 | 可用来源名称和 key                      |
| `GET /api/emby/public-sources`          | 启用的公共源名称和 key                  |
| `GET /api/emby/views`                   | 媒体库视图                              |
| `GET /api/emby/list`                    | 分页媒体列表、排序和库筛选              |
| `GET /api/emby/search`                  | 搜索媒体                                |
| `GET /api/emby/detail`                  | 媒体详情和剧集                          |
| `GET /api/emby/audio-streams`           | 音轨信息                                |
| `GET /api/emby/play/[token]/[filename]` | 播放代理，路径中的 token 不替代登录身份 |

播放页使用 `/play?source=emby_home&id=MEDIA_ID` 这样的地址，`home` 是来源 key。接口实现见 [Emby 路由](../../src/app/api/emby)，认证和播放地址生成见 [emby.client.ts](../../src/lib/emby.client.ts)。

当前集成面向 Emby。Jellyfin 与它有部分相似接口，但本项目没有据此承诺兼容全部版本。

本功能参考了 [MoonTVPlus](https://github.com/mtvpls/MoonTVPlus) 的 Emby 集成。
