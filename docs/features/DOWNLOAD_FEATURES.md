# M3U8 视频下载

播放页可以把 M3U8 视频按分片下载到浏览器，并保存为文件。任务支持暂停、继续、失败重试和从本地缓存重新导出。下载由当前浏览器执行，关闭页面后不会继续在服务器后台下载。

## 开始下载

1. 在播放页点击“下载”，选择当前集或需要下载的集数。
2. 在“下载管理”中查看任务、片段进度和错误信息。
3. 使用文件系统直写时，在浏览器弹出的窗口中选择保存位置。
4. 完成后检查文件能否正常播放，再删除不需要的任务缓存。

如果没有下载按钮，先确认管理员是否启用了“离线下载”。当前入口只接受 M3U8 播放地址，普通 MP4 链接不会走这套分片下载流程。

## 设置

点击下载任务面板右上角的设置按钮。设置保存在当前浏览器的 `downloadSettings` 中。

| 设置         | 默认值           | 可选范围                               |
| ------------ | ---------------- | -------------------------------------- |
| 下载线程数   | 6                | 1–16 个并发请求                        |
| 失败重试次数 | 3                | 0–10 次                                |
| 下载模式     | 按浏览器能力选择 | 文件系统直写、Service Worker、普通模式 |
| 保存格式     | TS               | 下载器支持 TS 和 MP4                   |

“线程数”指同时下载的片段数。提高并发能否提速，要看带宽、源站限流和代理负载；出现大量超时或 403 时，先减少并发。

当前播放页创建任务时固定使用 TS，设置面板里的 MP4 默认格式还没有接入这条路径。下载器内部的 MP4 处理使用 `mux.js` 转封装，不会把浏览器不支持的音视频编码重新编码成另一种格式。

## 下载模式

| 模式           | 工作方式                         | 使用条件与限制                                                                                        |
| -------------- | -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 文件系统直写   | 按分片顺序写入用户选择的文件     | 需要浏览器提供 `showSaveFilePicker`，通常见于桌面 Chrome、Edge；仍受磁盘空间和浏览器限制              |
| Service Worker | 通过浏览器下载通道写出数据       | 需要安全上下文和 Service Worker 支持，通常是 HTTPS 或 localhost；后台挂起、下载通道中断可能影响长任务 |
| 普通模式       | 缓存片段，完成后合并为 Blob 保存 | 不需要文件选择器，但合并大文件会占用较多内存                                                          |

没有已保存的设置时，检测顺序是文件系统直写、Service Worker、普通模式。流式写入器创建失败时，下载器会回退到普通模式。面板上的模式标签来自设置，不足以确认每个任务实际使用了哪种写入方式。

流式保存仍会使用分片缓存，不能据此认为文件大小或内存占用没有上限。大文件先在目标浏览器上试下载，确认磁盘空间、站点存储额度和最终文件完整性。

## 暂停、恢复与缓存

任务信息和片段保存在 IndexedDB；支持 Storage Buckets 的浏览器还会使用独立存储桶。刷新页面后，进行中的任务恢复为暂停状态，需要手动继续；已经失败的任务仍显示错误。

恢复有几个前提：

- 浏览器没有清除或回收站点缓存。
- 视频地址及其访问凭据仍然有效。
- 上游播放列表没有发生使旧分片失效的变化。

继续下载会复用已缓存的片段；重新建立文件写入器时，可能需要重新选择保存位置。它不会接着修改磁盘上一个任意的半成品文件。

“导出”使用本地缓存生成文件，分片缺失时会报错。删除任务会一并删除该任务的缓存，已经保存到下载目录的文件需自行管理。

## 常见问题

### 下载失败或只有部分进度

先查看任务中的失败片段，使用“重试失败片段”或“重试”。重试耗尽后任务会报错，不应把缺少分片的结果当成完整下载。

如果上游地址过期，重新打开播放页后创建任务。页面能播放而下载返回 403 时，检查源站的防盗链要求、本站代理权限和请求日志；相关规则见[代理与来源授权](../advanced/PROXY_CONFIG.md)。

### 文件保存失败

检查浏览器是否允许下载、是否取消了文件选择，以及磁盘和站点存储空间是否足够。可以先用一个短视频验证，再更换下载模式。

Service Worker 模式下，任务面板和浏览器下载列表都需要检查。长时间切到后台后出现文件不完整，尝试文件系统直写。

### 文件无法播放

TS 与 MP4 是不同封装格式，播放器对编码的支持也不同。MP4 转封装不会修复缺失分片或不兼容的编码；先确认任务没有错误，再用支持该编码的本地播放器检查。

下载器处理 AES-128、BYTERANGE 和带初始化段的部分 HLS 清单，但这不代表覆盖所有 HLS 变体。它不提供 DRM 解密；独立音轨组合及不断变化的直播清单需要另行验证。
