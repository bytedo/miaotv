# 部署安全与隐私

发现漏洞时，请按根目录的 [安全报告说明](../../SECURITY.md) 联系维护者。部署问题和不含敏感信息的错误可以提交到 [Issues](https://github.com/bytedo/miaotv/issues)。

## 账号与访问入口

为 `PASSWORD` 设置独立的长密码。它既是站长密码，也是登录会话的签名密钥；泄露后应更换并重新创建容器或重启服务。不要把真实的环境文件、数据库连接串、Cookie、配置备份或日志原文提交到仓库。

服务端存储的新实例默认允许注册。只供自己使用时，在开放访问前关闭“允许用户注册”；需要邀请他人时，可以启用邀请码或注册审核。关闭注册不会自动处理已经提交的待审核账号。

使用 HTTPS，并把应用放在受控反向代理后。代理需要保留正确的协议和主机信息；不要让公网绕过代理直连应用端口。登录、注册和密码重置入口可以在代理层加请求速率限制。

信任网络只允许部分匿名只读请求，不授予管理员权限。只有确认入口会清除并重写客户端 IP 请求头时，才启用 `TRUST_PROXY_HEADERS=true`。配置方法见 [信任网络](../authentication/TRUSTED_NETWORK.md)。

应用保留公开入口，包括登录、注册、下载页和 TVBox 等接口。不要假定设置站长密码后所有 URL 都需要登录。启用 TVBox 时，检查其独立的 Token 和 IP 白名单设置；从曾向普通账号暴露全局密钥的旧版本升级后，应轮换该密钥。

## 媒体代理

统一媒体代理仅接受 HTTP/HTTPS，拒绝 URL 内凭据、本机回环、链路本地、云元数据等目标。连接使用已经校验的 DNS 解析结果，每次重定向重新检查目标，跨 origin 跳转不携带 Cookie 或 Authorization。

已登录且获授权的账号可以访问明确配置并启用的私网媒体源。放行范围限定为来源的 origin，也就是协议、主机和端口，不会扩大到整个私网。匿名信任网络身份不能获得这项来源授权。

`DISABLE_SSRF_PROTECTION` 不再关闭这些检查。私有源不能通过任意来源标签授权其他目标，HLS 子清单、密钥和分片也要携带正确的来源上下文。详细行为见 [代理配置](../advanced/PROXY_CONFIG.md)。

## 凭据与用户数据

服务端存储可能保存账号资料、邮箱、播放记录、收藏、邀请码和服务配置。数据库卷及备份应限制访问；后台 `.dat` 导出不能代替数据库原生备份。调整存储或迁移旧数据前，先在隔离环境验证恢复步骤。

邮件和 Webhook 配置由站长管理。接口不回显 SMTP 密码或 Webhook 签名密钥，但数据库中仍需保存可供发送服务使用的配置。Webhook 模板中的邮箱、用户名等字段会发送给配置的接收方；使用 GET 模板时，字段还可能进入对方的访问日志。

第三方登录需要将浏览器跳转到对应身份服务。当前 OIDC 实现有提供商兼容限制，不能仅凭后台存在某个图标判断登录已经可用；接入前阅读 [OIDC 配置与限制](../authentication/OIDC_SETUP.md)。

项目不附带影视资源，部署者自行配置媒体源。应用可以缓存媒体数据，下载功能也会保存用户请求的内容；应按自己的部署方式管理缓存、下载文件与保留时间。使用和分发遵循 [LICENSE](../../LICENSE)，访问或下载第三方内容需取得相应授权。
